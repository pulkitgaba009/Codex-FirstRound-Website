# 🧠 Codex Round - Quiz Application (MERN Stack) 

A **full-stack Quiz Application** developed using the **MERN stack (MongoDB, Express.js, React.js, and Node.js)**, designed to deliver a **scalable, secure, and high-performance online assessment platform**.

The application enables **real-time quiz participation**, **dynamic question rendering**, and **server-side answer validation** to ensure accuracy, fairness, and reliability during assessments. Special attention has been given to **performance optimization and efficient API handling**, making the system suitable for **multiple concurrent users**.

This project was **entirely designed, developed, and maintained independently**, covering both frontend and backend development. It has been **successfully used in live coding competitions and practice assessments**, proving its reliability in real-world scenarios.


---

## 🚀 Project Overview

The Quiz Application provides a **real-time, interactive quiz experience** where users can attempt quizzes within a defined time limit and receive instant results.

The main goal of this project is to demonstrate:
- Proctoring logic to avoid any kind of cheeting
- Secure REST API design
- Optimized database interactions
- Real-world MERN stack implementation

## ⚙️ Installation & Setup

### Prerequisites
- Node.js
- MongoDB

---

### Clone Repository
```bash
git clone https://github.com/pulkitgaba009/Codex-FirstRound-Website.git
cd quiz-application
```

### Backend Setup
```bash
cd backend
npm install
npm run dev
```

### Frontend Setup
```bash
cd backend
npm install
npm run dev
```
